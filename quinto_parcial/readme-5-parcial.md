# Quinto parcial — Diapositivas

Diapositivas HTML interactivas que recorren la Tarea 2: reparacion, graficos
y modelo de prediccion del resultado final a partir del marcador del medio
tiempo (Premier League 2024/25).

## Como abrir

1. Hacer doble clic en `index.html` (se abre en el navegador, sin servidor ni
   internet).
2. Navegar con las flechas **izquierda / derecha** del teclado, o con los
   botones "Anterior / Siguiente".
3. El contador de diapositiva aparece arriba a la derecha.

## Contenido

| Diapositiva | Tema |
| --- | --- |
| 1–2 | Pregunta del dataset |
| 3–4 | Reparacion: lectura, parseo, auditoria y decisiones |
| 5–7 | Graficos: scatter, matriz de confusion y remontadas |
| 8–11 | Modelo: y/X, split, baseline, metricas y probabilidades |
| 12 | Conclusiones y limites |

## Archivos

- `index.html` — diapositivas.
- `*.png` — figuras exportadas de los notebooks (en esta misma carpeta).
